# Decisions

1. **React 18.** `npm i react` installs 19 today; pinned to 18 as the plan states.
2. **Demo ampacity table is synthetic.** The plan forbids inventing standards
   data but also asks for an illustrative table. Values are generated by
   `It = round(10.5 · csa^0.75 · method · insulation · phases)` (method B 0.85,
   C 1.0, E 1.1; XLPE 1.25; 3P 0.9). They are not BS 7671 numbers and the file
   says so. A real table is loaded from `src/data/ampacity.local.json`
   (git-ignored).
3. **Voltage-drop advisory.** For csa ≥ 25 mm² a passing drop is reported as
   `ADVISORY` (reactance not included) rather than adding a second result.
4. **Overall status.** `INPUT_ERROR` > `FAIL` > `ADVISORY` (also used when a
   check is `NOT_CHECKED`, e.g. no ampacity entry) > `PASS`.
5. **RCD rule** returns no result at all when it does not apply, so n/a rules
   do not clutter the card.
6. **Suggestions** are accepted only if the engine re-checked the whole circuit:
   the target check passes and nothing that was not failing now fails.
   Families tried: larger line csa, shorter run, lower curve, lower rating,
   larger cpc, 30 mA RCD, higher rating.
7. **CSV ids** are `row-<line>` so import is deterministic; the UI assigns its
   own ids when a circuit is created by hand.
8. **Fault current** uses cold Zs = Ze + (R1+R2) at 20 °C, as the plan states.
9. **Earth-fault limit** is `Cmin · Uo / (k · In)` as the plan states, with the
   0.8 factor applied only to on-site measurements.

10. **Settings.** All tunable assumptions live in `engine/settings.ts` (`Settings` + `SETTING_FIELDS`). Every check takes an optional `Settings` argument defaulting to the plan's values, so the engine stays pure and the golden tests are unchanged. The UI stores settings in the saved state (included in backups), validates ranges, and prints the values used, with changes flagged, in every report. The defaults remain unverified `TODO(verify)` values.

11. **AI features.** Optional, off by default, bring-your-own-key, via the official `@anthropic-ai/sdk` called from the browser (`dangerouslyAllowBrowser`), which is acceptable for a personal key but not for a shared deployment. This adds two runtime dependencies (`@anthropic-ai/sdk`, `zod`) beyond the plan's react/react-dom; both are lazy-loaded. Structured output (`messages.parse` + zod schema, every field nullable so the model must say 'unreadable' instead of guessing). Humans confirm every row; the engine stays deterministic. The key lives outside the app state so it never enters backups. Default model `claude-opus-5-5`; Sonnet 5.5 and Haiku 5.5 selectable.
